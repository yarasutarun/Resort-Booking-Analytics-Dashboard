# Resort-Booking-Analytics-Dashboard
This project is an interactive Excel dashboard that provides a detailed analysis of resort booking data. It highlights key business metrics such as booking volume, cancellation rate, average stay duration, repeat guests, room and meal preferences, and deposit types. 
## 📊 Features  

- **KPIs Tracked:**  
  - Total Bookings  
  - Canceled %  
  - Average Stay Duration  
  - Repeated Guests %  
  - Number of Countries  

- **Visuals & Charts:**  
  - Booking Trends by Status (Line Chart)  
  - Most Booked Meal Plan (Bar Chart)  
  - Top Countries by Booking Volume (Horizontal Bar Chart)  
  - Guest Composition by Resort (Stacked Column Chart)  
  - Room Assignment Discrepancy (Donut Chart)  
  - Special Request Ratio (Donut Chart)  
  - Parking Required % (Donut Chart)  
  - Deposit Type Distribution (Donut Chart)  

- **Filters (Slicers):**  
  - Room Type  
  - Resort Name  
  - Year  
  - Month  
## 💡 Tools Used  
- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Slicers  
- Conditional Formatting  
- Icons and SmartArt for visual KPIs  

## 🔧 How to Use  
1. Open the `Resort_Booking_Analytics_Dashboard.xlsx` file in Excel.  
2. Use the slicers on the right to filter data by year, room type, resort, or month.  
3. Hover over charts for detailed values and trends.  
4. Modify or expand charts as needed using the underlying Pivot Tables.
